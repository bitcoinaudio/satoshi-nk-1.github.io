# satoshi-nk-1.github.io

Welcome to the source repository for [satoshi-nk-1.github.io](https://satoshi-nk-1.github.io), a public-facing static site dedicated to the BitcoinAudio and Satoshi NK-1 project.

## 🚀 Project Overview

This repository contains the source code and content for the Satoshi NK-1 website, which serves as an informational hub for BitcoinAudio, experimental blockchain audio, cryptographic art, and related community projects. The site is built using [GitHub Pages](https://pages.github.com/) and leverages static site generation for fast, reliable, and decentralized content delivery.

## 🧩 Features

- **Project Documentation**: Detailed documentation about BitcoinAudio, Satoshi NK-1, and related experiments.
- **Audio Demos**: Embedded and downloadable blockchain-encoded audio samples.
- **Art & Media**: Showcase of cryptographic art and generative media.
- **Community Links**: Resources for contributors, collaborators, and enthusiasts.
- **Open Source**: Contributions welcome! All source code and content are open for collaboration.

## 🛠️ Local Development

To work on the site locally:

1. **Clone the repository**
    ```bash
    git clone https://github.com/bitcoinaudio/satoshi-nk-1.github.io.git
    cd satoshi-nk-1.github.io
    ```
2. **Open `index.html` directly in your browser**
    - For most changes, no build step is required.
    - If you use Jekyll or another static site generator, follow its setup instructions.

3. **(Optional) Serve locally with Python**
    ```bash
    python3 -m http.server
    ```
    Then open [http://localhost:8000](http://localhost:8000) in your browser.

## 🌍 Deployment

Deployment is automatic via [GitHub Pages](https://pages.github.com/). Updates to the `main` branch are published at [https://satoshi-nk-1.github.io](https://satoshi-nk-1.github.io).

If using a custom domain, ensure the `CNAME` file is present and DNS is configured.
